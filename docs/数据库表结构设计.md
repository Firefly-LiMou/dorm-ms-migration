## 数据库表结构设计（MySQL 8.0）

### 一、设计原则说明

1. **精简适配练手目标**：仅覆盖必做核心模块，表结构保持7张核心表，避免过度设计，聚焦前后端联调与协作开发
2. **统一用户体系**：学生与管理员共用用户表，通过角色字段区分，简化权限逻辑，适配 Sa-Token 快速开发
3. **三级层级关联**：楼栋 → 房间 → 床位 三级关联，通过逻辑外键+索引保证查询效率，不强制物理外键，降低开发调试成本
4. **状态标准化**：所有业务状态使用 `tinyint` 枚举值，统一约定规则，便于代码常量维护
5. **公共字段统一**：所有业务表内置创建时间、更新时间字段，适配 MyBatis-Plus 自动填充
6. **适度冗余设计**：报修、日志等表适度冗余关键字段（如房间号、操作人姓名），减少联表查询，提升开发效率
7. **物理删除策略**：删除操作采用物理删除，删除前必须校验下级关联数据，存在关联数据时禁止删除，不引入逻辑删除字段

------

### 二、详细表结构设计

#### 1. 用户表 `sys_user`

存储学生、系统管理员的账号与基础信息，统一身份体系

| 字段名        | 类型         | 约束                                                         | 说明                                       |
| ------------- | ------------ | ------------------------------------------------------------ | ------------------------------------------ |
| `user_id`     | bigint       | PRIMARY KEY, AUTO_INCREMENT                                  | 用户主键ID                                 |
| `username`    | varchar(32)  | UNIQUE, NOT NULL                                             | 登录账号（学生为学号，管理员为管理员账号） |
| `password`    | varchar(128) | NOT NULL                                                     | 登录密码（加密存储）                       |
| `real_name`   | varchar(32)  | NOT NULL                                                     | 真实姓名                                   |
| `role`        | char(10)     | NOT NULL, DEFAULT 'student'                                  | 角色：`student`-学生，`admin`-管理员       |
| `gender`      | char(2)      | NULL                                                         | 性别：男/女                                |
| `phone`       | varchar(11)  | NULL                                                         | 联系电话                                   |
| `status`      | tinyint      | NOT NULL, DEFAULT 1                                          | 账号状态：1-正常，0-禁用                   |
| `create_time` | datetime     | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 创建时间                                   |
| `update_time` | datetime     | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                                   |

**索引**：`idx_username(username)` 唯一索引，`idx_role(role)` 普通索引

------

#### 2. 楼栋表 `dorm_building`

公寓楼栋基础数据

| 字段名          | 类型        | 约束                                                         | 说明                            |
| --------------- | ----------- | ------------------------------------------------------------ | ------------------------------- |
| `building_id`   | bigint      | PRIMARY KEY, AUTO_INCREMENT                                  | 楼栋主键ID                      |
| `building_no`   | varchar(20) | UNIQUE, NOT NULL                                             | 楼栋编号（如 1、2、东1）        |
| `building_name` | varchar(50) | NOT NULL                                                     | 楼栋名称（如 一号学生公寓）     |
| `floor_count`   | int         | NOT NULL                                                     | 总楼层数                        |
| `area`          | varchar(20) | NULL                                                         | 所属区域（如 东区、西区、南区） |
| `create_time`   | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 创建时间                        |
| `update_time`   | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                        |

**索引**：`idx_building_no(building_no)` 唯一索引

------

#### 3. 房间表 `dorm_room`

房间基础信息，关联所属楼栋

| 字段名        | 类型        | 约束                                                         | 说明                              |
| ------------- | ----------- | ------------------------------------------------------------ | --------------------------------- |
| `room_id`     | bigint      | PRIMARY KEY, AUTO_INCREMENT                                  | 房间主键ID                        |
| `building_id` | bigint      | NOT NULL                                                     | 所属楼栋ID                        |
| `room_no`     | varchar(20) | NOT NULL                                                     | 房间编号（如 101、202）           |
| `floor`       | int         | NOT NULL                                                     | 所在楼层                          |
| `bed_count`   | int         | NOT NULL, DEFAULT 4                                          | 床位数（如 4人间、6人间）         |
| `room_type`   | varchar(20) | NULL                                                         | 房间类型（如 标准四人间、六人间） |
| `create_time` | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 创建时间                          |
| `update_time` | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                          |

**索引**：`uk_building_room(building_id, room_no)` 联合唯一索引，`idx_building_id(building_id)` 普通索引

------

#### 4. 床位表 `dorm_bed`

床位信息，关联所属房间，记录入住状态

| 字段名        | 类型        | 约束                                                         | 说明                       |
| ------------- | ----------- | ------------------------------------------------------------ | -------------------------- |
| `bed_id`      | bigint      | PRIMARY KEY, AUTO_INCREMENT                                  | 床位主键ID                 |
| `room_id`     | bigint      | NOT NULL                                                     | 所属房间ID                 |
| `bed_no`      | varchar(10) | NOT NULL                                                     | 床位编号（如 1、2、3、4）  |
| `status`      | tinyint     | NOT NULL, DEFAULT 0                                          | 入住状态：0-空闲，1-已入住 |
| `create_time` | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 创建时间                   |
| `update_time` | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                   |

**索引**：`uk_room_bed(room_id, bed_no)` 联合唯一索引，`idx_room_id(room_id)` 普通索引，`idx_status(status)` 普通索引

------

#### 5. 入住记录表 `dorm_checkin`

学生入住/退宿的业务记录，承载学生与床位的关联关系，支持历史追溯

| 字段名          | 类型         | 约束                                                         | 说明                         |
| --------------- | ------------ | ------------------------------------------------------------ | ---------------------------- |
| `checkin_id`    | bigint       | PRIMARY KEY, AUTO_INCREMENT                                  | 入住记录ID                   |
| `user_id`       | bigint       | NOT NULL                                                     | 学生用户ID                   |
| `bed_id`        | bigint       | NOT NULL                                                     | 入住床位ID                   |
| `checkin_time`  | datetime     | NOT NULL                                                     | 入住时间                     |
| `checkout_time` | datetime     | NULL                                                         | 退宿时间（入住中为NULL）     |
| `status`        | tinyint      | NOT NULL, DEFAULT 1                                          | 记录状态：1-入住中，2-已退宿 |
| `operator_id`   | bigint       | NOT NULL                                                     | 办理人ID（管理员）           |
| `remark`        | varchar(255) | NULL                                                         | 备注                         |
| `create_time`   | datetime     | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 创建时间                     |
| `update_time`   | datetime     | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                     |

**索引**：`idx_user_id(user_id)` 普通索引，`idx_bed_id(bed_id)` 普通索引，`idx_status(status)` 普通索引

> 设计说明：学生当前住宿信息通过「status=1 的入住记录」关联查询，不直接在用户表冗余床位ID，避免数据不一致，适配调宿、多次入住场景。同一床位仅允许存在一条「status=1」记录，入住分配时由业务层对床位行加锁（SELECT ... FOR UPDATE）保证并发安全。

------

#### 6. 报修表 `dorm_repair`

报修单全生命周期记录，覆盖提交、处理、完成状态流转

| 字段名          | 类型        | 约束                                                         | 说明                                         |
| --------------- | ----------- | ------------------------------------------------------------ | -------------------------------------------- |
| `repair_id`     | bigint      | PRIMARY KEY, AUTO_INCREMENT                                  | 报修单ID                                     |
| `user_id`       | bigint      | NOT NULL                                                     | 报修学生ID                                   |
| `room_id`       | bigint      | NOT NULL                                                     | 报修房间ID（冗余字段，快速定位楼栋）         |
| `repair_type`   | tinyint     | NOT NULL, DEFAULT 0                                          | 报修类型：0-水电故障，1-家具损坏，2-网络问题，3-其他 |
| `content`       | text        | NOT NULL                                                     | 报修内容详情                                 |
| `contact_phone` | varchar(11) | NOT NULL                                                     | 联系电话                                     |
| `status`        | tinyint     | NOT NULL, DEFAULT 0                                          | 报修状态：0-待处理，1-处理中，2-已完成       |
| `handle_result` | text        | NULL                                                         | 处理结果                                     |
| `handle_time`   | datetime    | NULL                                                         | 处理完成时间                                 |
| `handler_id`    | bigint      | NULL                                                         | 处理人ID（管理员）                           |
| `create_time`   | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP                          | 提交时间                                     |
| `update_time`   | datetime    | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                                     |

**索引**：`idx_user_id(user_id)` 普通索引，`idx_status(status)` 普通索引，`idx_room_id(room_id)` 普通索引，`idx_create_time(create_time)` 普通索引

------

#### 7. 操作日志表 `sys_operation_log`

Spring AOP 自动记录的管理端操作日志，支持审计追溯

| 字段名           | 类型         | 约束                                | 说明                                        |
| ---------------- | ------------ | ----------------------------------- | ------------------------------------------- |
| `log_id`         | bigint       | PRIMARY KEY, AUTO_INCREMENT         | 日志主键ID                                  |
| `operator_id`    | bigint       | NOT NULL                            | 操作人ID                                    |
| `operator_name`  | varchar(32)  | NOT NULL                            | 操作人姓名（冗余字段，避免联表）            |
| `module`         | varchar(50)  | NOT NULL                            | 操作模块（如 楼栋管理、报修管理、入住管理） |
| `operation_type` | varchar(20)  | NOT NULL                            | 操作类型：新增、修改、删除（仅写操作，由 AOP 切面记录） |
| `content`        | varchar(500) | NOT NULL                            | 操作详情描述                                |
| `ip_address`     | varchar(50)  | NULL                                | 操作IP地址                                  |
| `create_time`    | datetime     | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 操作时间                                    |

**索引**：`idx_operator_id(operator_id)` 普通索引，`idx_create_time(create_time)` 普通索引
